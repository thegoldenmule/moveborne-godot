# Query
This tool can be used to run SQL queries against your Analytics data warehouse. You can use this tool to query your custom events, Snapser provided events, and any other data that you have stored in your Analytics data warehouse.

<Note>
  Snapser provides a Business Intelligence tool that allows you to write queries, save them, create custom charts and add them to dashboards. This is a paid feature and is available to all Snapser Premium users.
</Note>


## Querying Data
You can only run `Select` queries in this tool. You can use the SQL editor to write your query and then click on the **Run Query** button to execute it. The results will be displayed in a table below the editor.

## Query Limit
The default query limit is set to 500 rows.
